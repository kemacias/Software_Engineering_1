## How would you describe the difference between "programming" and "software engineering"?

### "Programming" refers more to the simple act of writing code. This could be little code snippets to accomplish simple tasks. Software Engineering is defined as the systematic application of scientific tech knowledge, methods and experience in design. This means it is the entire process of creating applications as a whole. Back end and front end and how it interacts with the world.
