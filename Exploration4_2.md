## 1. What's the difference between a class variable and an instance variable?
### Class variables belong to a class. Instance variables belong to an object. 

## 2. You have a class variable x and 120 instances of the class. How many different xs are there?
### There is one x and all 120 instances share it. 

## 3. You have an instance variable y and 120 instances of the class. How many different ys are there?
### there are 120 y's. one for each instance.
