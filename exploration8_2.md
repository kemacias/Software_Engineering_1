## What is the difference between a GitHub fork and a regular repo clone?
A github fork is posted on a remote server, and a regular repo clone is downloaded from the remote server and stored locally. 

## Why is it a good practice to submit PRs on branches instead of putting them all on main?

Submitting PRs on branches allows you to work on multiple features or bug fixes simultaneously without affecting the main branch.

## Why should you sync with the upstream repo before you make a PR?

Syncing with the upstream repo before making a PR ensures that your branch is up to date with the latest changes from the main branch.

## What are the advantages and disadvantages of adding collaborators versus using PRs?

Adding collaborators allows you to work together on a project, while using PRs allows you to review and merge changes from other contributors.1
